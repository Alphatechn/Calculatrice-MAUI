# Calculatrice .NET MAUI

Calculatrice mobile réalisée avec .NET MAUI (Activité n°4 – Atelier de développement mobile).

## Fonctionnalités
- Opérations de base : +, −, ×, ÷, nombres décimaux, C, ⌫, ±, %
- Division par zéro gérée sans plantage
- Opération en cours affichée au-dessus du résultat
- Bonus : √, x², 1/x, historique des calculs, « = » répété
- Disposition adaptative en portrait et en paysage

## Lancer le projet
Ouvrir la solution dans Visual Studio, choisir un émulateur Android, puis lancer (F5).
